# Личный финансовый помощник

Telegram-бот для записи доходов и расходов в Google Таблицу.

Переменные Bothost:

- `TELEGRAM_BOT_TOKEN`
- `GOOGLE_SHEET_ID=17Ro3smWBGbTVmxGQGYuK0dZxI-2y4lJzXFYxchQJMNU`
- `GOOGLE_SERVICE_ACCOUNT_JSON` — JSON-ключ сервисного аккаунта Google, которому расшарена таблица на email сервисного аккаунта.
- `TELEGRAM_USER_ID` — Telegram ID владельца для ежедневных отчётов.
